<h3>🚀 Customer Retention Prediction System</h3>

<p>
An advanced <b>Machine Learning based Telecom Customer Churn Prediction System</b> built using 
<b>Python</b>, <b>Flask</b>, and <b>Scikit-Learn</b>.
</p>

<p>
The project predicts whether a customer is likely to:
</p>

<ul>
<li>✅ Stay with the telecom company</li>
<li>⚠️ Leave the telecom service</li>
</ul>

<p>
This project includes:
</p>

<ul>
<li>📊 Data Preprocessing</li>
<li>🧹 Missing Value Handling</li>
<li>📈 Feature Engineering</li>
<li>⚡ Feature Scaling</li>
<li>🤖 Machine Learning Prediction</li>

<h1 align="center">🚀 Installation & Setup</h1>

<h3>1️⃣ Clone Repository</h3>

<pre>
git clone https://github.com/your-username/customer-retention-prediction-system.git
</pre>

<h3>2️⃣ Navigate to Project</h3>

<pre>
cd customer-retention-prediction-system
</pre>

<h3>3️⃣ Create Virtual Environment</h3>

<pre>
python -m venv .venv
</pre>

<h3>4️⃣ Activate Virtual Environment</h3>

<pre>
.venv\Scripts\activate
</pre>

<h3>5️⃣ Install Requirements</h3>

<pre>
pip install -r requirements.txt
</pre>

<h3>6️⃣ Run Flask Application</h3>

<pre>
python app.py
</pre>
